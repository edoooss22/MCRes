Резидентность страниц

Обнаружение чтения карты структуры ВМ (gHotSpotVMStructs)

Кратко:
Резидентность страниц - страница лежит в физической памяти (рабочем множестве) или выгружена. Обращение к нерезидентной странице вызывает page fault и поднимает её - причём и внешнее чтение (ReadProcessMemory) тоже.
External читы/макросы с незахардкожеными смещениями (чтобы работало на разных версиях) получают смещения чтением карты структур ВМ (gHotSpotVMStructs).

ГЛАВНОЕ, прогу запускать с флагом -c:
